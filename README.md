語音是人類最自然、最便利的資訊交換方式。而在許多特定情境下，傳統的聲學語音通訊會受到限制。例如，傳統語音辨識對於因疾病或手術而失去發聲能力的患者而言便失效；在高噪音環境或需要高度隱私的場合，依賴聲音的通訊方式也顯得不切實際。因此，無聲語音介面 (Silent Speech Interface, SSI) 技術應運而生，成為近年來人機互動領域的熱門研究方向。 
目前的 SSI 技術涵蓋了多種感測模式。例如，有研究探討使用雷達 (Radar)進行非接觸式的連續音素辨識 [1,2]，或是單純利用人臉影像進行語音特徵的生成 [3]。然而，表面肌電圖 (Surface Electromyography, sEMG) 被認為是實現無聲語音辨識（Silent Speech Recognition, SSR）最實用且直接的選項之一，因為它能直接捕捉大腦下達給臉部與喉部肌肉的運動神經指令，在沒有實際發出聲音的情況下，依然能模擬語音產生的過程。 
儘管 sEMG 具有極大的潛力，但目前的先進研究多半依賴高密度表面肌電圖 (High-Density Surface Electromyography, HD-sEMG)。例如，使用高達 64 個通道的電極陣列來捕捉臉部與頸部的時空特徵 [4]。這種作法雖然準確率高，但在實際應用中卻面臨硬體成本高昂、運算資源龐大、且使用者配戴極度不適等問題。因此，本研究致力於開發一套低通道數、低成本且高精準度的 sEMG 無聲語音辨識系統，透過優化「電極貼片設計」與「精準肌肉定位」，證明在有限的硬體資源下，依然能達成高準確率的語音意圖分類，並透過機器學習進行分析。
